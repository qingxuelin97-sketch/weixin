# 「AI 微信」个人版 —— 总体规划

> 由 17 个讨论/裁判子代理两轮辩论裁决后汇总（第一轮 4 提案；第二轮 13 个专项提案 + 3 个
> 分域裁判）。用户确认：主力手机 Android、剧情模式押后到 V3、大陆网络+有代理。这是项目的
> 长期规划真源；里程碑推进以此为准。

## 背景

个人自用（不商用不公开）的「AI 微信」App：1:1 复刻微信大陆版 8.x（以用户真机 Android 版
微信为唯一基准）。核心与最优先项是 AI 板块：任意配置的智能体充当好友/群友、智能单聊、智能
群聊互动、智能朋友圈、（V3）剧情模式、NSFW 开关。LLM 适配 DeepSeek / MiniMax(含 TTS) /
OpenCode Zen。local-first：数据全本地、无自建服务器、API key 用户自填。

## 技术栈（裁决：Web-first + Capacitor）

Vite + React 18 + TypeScript strict + Capacitor 7。Android APK 为第一交付物；iOS/异地由
同一代码的 PWA 承接。状态 zustand；数据库 @capacitor-community/sqlite + Drizzle（Web 端切
wa-sqlite/OPFS 双驱动）；特效走 CSS 3D transform。RN 出局，Flutter 封存为唯一熔断预案。

**第 1 周熔断门（≥2 项失败→转 Flutter）**：
a) 真机 WebView 2 万条倒序消息 fling 无白屏卡顿；
b) CapacitorHttp 直连 DeepSeek/MiniMax 成功（大陆网络）；
c) 键盘↔表情/+号面板三态切换零跳变原型成立。

传输层 V1 非流式（CapacitorHttp 免 CORS）+ "对方正在输入…" 占位 + 结构化气泡按延迟逐条播放；
Provider 接口即日定为流式签名 `AsyncIterable<Bubble>`。

## LLM 适配层（N 槽位，三家一等公民预设）

通用 OpenAI 兼容 Provider 槽位（base_url + key + 模型名可自填，每 Provider 留备用 base_url）。
- DeepSeek（国内直连）：deepseek-chat / deepseek-reasoner；稳定前缀吃缓存；prefix 破冰；R1 思考链剥离。
- MiniMax（国内直连）：文本 + T2A v2 TTS（model/voice/emotion 全配置化）+ 文件转写 ASR fallback。
- OpenCode Zen（走代理）：宽松通道默认预设（可换 OpenRouter）。
路由默认：日常/导演/记忆抽取=deepseek-chat；复杂=deepseek-reasoner；语音=MiniMax TTS；
NSFW 全开=宽松通道。降级链：软化重试+prefix → 宽松链粘性 10 条 → 人设化兜底，原始报错永不上屏。

## AI 核心系统（摘要，详见各 spec）

- 人设卡：内部 schema + SillyTavern V2 双向兼容；分层 system prompt（基底→人设→关系→NSFW 边界→记忆→场景）。
- 记忆：结构化事实（V1 无向量），witness 作用域流动，二维关系边，四触发抽取，证据链去幻觉。
- 群聊：规则预筛 + 导演精排；全员并发生成、按 priority 顺序播放；NDJSON 逐行气泡；用户消息硬中断。
- 拟真引擎：结构化多气泡 + 打字延迟；scheduled_actions 单队列 + simulate() 纯函数；主动消息三层。
- 朋友圈（M4）：掷骰发帖 + 亲密度错峰赞评；无条件 SFW。
- NSFW：三级（关/暧昧/全开）；全开档代码层禁走国内官方端点；隔离 + 隐藏好友 PIN。
- 语音：MiniMax TTS 发送即生成；通话 V2 壳 / M5 来电 / V3 字幕通话；端上 ASR。
- 剧情（V3）：GM 注入 + 线性节拍表；V1 预埋 (script_id,seq) 标签与 memory source=story。

## 功能范围

- **V1（M1-M3）**：4 Tab 壳 / 单聊 / 群聊≤4 AI / 图片查看 / 人设编辑 / API 配置 / 联系人详情
  / 红包全流程 / 转账 / 零钱 / 语音消息 TTS / NSFW 三级开关。
- **V2（M4-M5）**：朋友圈 / 离线回填 / 预调度通知 / 备份 / 通话壳 / Android 常驻服务 / AI 来电
  / 撤回戏 / 搜索 / 群详情 / 新的朋友 / ST 卡导出 / 八卦扩散。
- **V3**：剧情轻量版 / 深色 / 字幕通话 / 收藏 / 字号 / 聊天背景。
- **永不做**：小程序运行时 / 真实支付通信 / 账号体系 / 视频号功能化 / 全双工语音 / 真实视频通话。

### M4 完成情况（2026-08）

已交付：朋友圈（发布 / feed / 错峰赞评 / 配图槽位）、离线回填（`simulate()` 纯函数 + 单队列
物化）、通知抽象层与内容分级、备份恢复 `.aiwx`。详见 `specs/moments.md`、`specs/backfill.md` 与 `specs/backup.md`。

顺带修掉一处 M2 遗留缺陷：**L0 主动消息自 M2 起从未触发**——`scheduleHeartbeat()` 有定义无
调用方，`heartbeat` handler 也从未注册。本轮接上（commit 4b7b3e5）。

**尚未真机验证的部分**：预调度通知的锁屏投递需要 APK，属 M5 构建范畴。当前 Web 端
`scheduleNotifications` 如实返回 0（浏览器无法为未运行的页面排期），不谎报成功。
「离线 8h 重开首条 3s 内落」的时序在纯函数层已由单测钉住，端到端计时同样待 APK。

### M5 进行中（2026-08）

**已交付且可在开发环境验证：**
- 搜索（联系人/聊天/聊天记录/朋友圈四类分组、绿色高亮、摘要开窗）——三处搜索按钮从 M1
  起就是死按钮，现已接上。详见 `specs/search.md`。
- **离线群聊回填**：完成标准的后半句「15min 心跳≤2 事件」此前完全没有实现——`simulate()`
  声明了 `SimGroup` 却从不读，调用方硬编码 `groups: []`。现已实现并由单测钉死
  （故意把间距改坏后 3 条断言立刻转红，不是摆设测试）。
- 修掉 M4 三处接线缺陷：`notify.ts` 零调用方（死代码）、回填只在冷启动跑一次
  （无前台生命周期监听）、`ActionKind` 与 schema 真源枚举漂移。
- **CI 出 APK**（`.github/workflows/release.yml`）：debug APK 每次构建都产出为
  artifact，这是当前的真机验收通道。

**尚未做：** 常驻服务真发、通知栏对话（RemoteInput 直接回复）、AI 来电全屏、撤回戏、
白名单向导。前两项需要自定义 Java/Kotlin，与 `android/` 是生成物存在冲突，
需先定 overlay 方案；白名单向导依赖真机厂商行为，写盲代码没有意义。

**开发容器的硬限制（已实测）：** `dl.google.com` 被出网策略 403，Android SDK 与 Google
Maven 同在该域名下 → 容器内**永远构建不了 APK**；且无 `/dev/kvm`/`vmx`/`emulator`
→ 即便能构建也跑不起来。故 APK 只能由 CI 产出，真机验收权仍在用户手上。

**待用户一次性操作：** 生成签名 keystore 并配 4 个 GH Secret（见
`specs/build-distribution.md`）。在那之前只有 debug 包，**换版本需卸载重装、本地数据会清空**，
升级前请先导出 `.aiwx`。

### M-A 智能体系统升级（2026-08，用户指定专项）

重点 = 拟人化 · 主动性 · AI↔AI 私信化学（即 V2 清单的「八卦扩散」）。详见 `specs/agents.md`。

已交付：relations 层接线（定义于 M2、从未被调用）、反 AI 腔硬规则、回复前阅读延迟、
零存储每日心情、撤回戏（队列化 + 用户长按 + 重新编辑 + 圆场话）、素材化开场白
（记忆追问/分享朋友圈/问候三源）、未回 nudge（每条被无视的消息一辈子只追一次）、
AI↔AI 隐藏私信 + 八卦双向入记忆 + p=0.5 群聊外溢。

成本纪律：DM 8–20h 链式间隔 ≈≤2 场/天（间隔即预算，无计数器）；回填不生成 DM；
nudge/开场白计入原有 heartbeat 调用。**对话质量需真机 + 真 key 验收**——
本容器全部验证均为零真 API（FakeProvider / 纯函数 / E2E 注入）。

兜底。3. DeepSeek 审核收紧可能波及暧昧档→预留切宽松通道开关。4. capacitor-community/sqlite
单维护→Drizzle 抽象兜底。5. CI 像素与真机字体残差→判定权在用户真机。6. 国产 ROM 杀后台→白名单向导。
