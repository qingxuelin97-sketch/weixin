### 本轮最值得记住的几条

**1. 「写了没接线」的第 N 次变体：麦克风按钮**。M-I9 交付了完整的按住说话浮层 +
ASR，但松开只把文本塞进输入框——微信真正的「发语音消息」在 App 里根本不存在，
而 manifest 连 RECORD_AUDIO 都没声明（J0 才补），也就是说那条语音线在真机上
**从来没有可能拿到麦克风**。两处都修完，J7a 才算真的有语音消息。

**2. 通知默认是静音的，而且没人会想起来问**。21 种排期动作里只有 4 种出通知；
她转账、打电话、群里聊起来，App 一关全部无声。修法不是「补几个通知」而是
`NOTIFY_STANCE` 台账：`Record<ActionKind, eligible | silent+why>`，编译期强制全覆盖，
守卫再断言键集合与 `SCHEDULED_ACTION_KINDS` 相等。**新增 kind 不表态直接转红**。

**3. 成本闸要长在结构里，不是配置里**。群语音通话每轮恰好 1 次 LLM 生成——
「谁接话」由零成本纯函数 `pickCallSpeaker`（种子化加权轮盘）决定，而不是一次导演
LLM 往返。通话对延迟敏感，导演往返本身就出戏；把它做成纯函数，成本上限就成了
代码形状而不是一个可以被调大的常量。

**4. 动态权限旗 vs 静态 manifest 属性**。锁屏来电需要 `showWhenLocked`，但写进
manifest 就是把**整个 App** 抬到 keyguard 之上——锁屏点一条消息通知就能翻聊天记录。
正确做法是按 intent 动态设旗并对非来电 intent 显式复位（singleTask 实例活得比
一次来电久，不复位＝旧旗永久漏全 App）。

**5. 体积棘轮不奖励懒拆——已在 J10 修好**。原来的 check:size 统计**总 gzip**
（含懒 chunk），所以把模块拆成 lazy chunk 一个字节都不降，指标在悄悄惩罚正确
的修法（我这一轮自己踩了两次）。J10 拆成主/懒双账本：主 = index.html 引用的入口
chunk + 全部 CSS，懒 = 其余。拆开后第一个发现是**主 361KB / 懒 14KB**——几乎整个
App 都是冷启动重量，四个懒 chunk 是零头。

**6. 守卫可以「看起来在工作」而实际只查了一小半**。这一轮撞了两次：
① J11 的全类型清扫第一版断言「没有 [类型名] 上屏」，我删掉一个卡片分支验证它，
**全绿**——switch 的兜底是 `content ?? [type]`，带内容的卡片会静默降级成普通文字
气泡。补了「必须走自己那个分支」才真的会红。
② 同一个文件里从源码扫消息类型联合时，按第一个 `;` 截断——而好几个成员的文档
注释里带分号，联合被悄悄砍到前九个。剥注释后才是十五个。
**变异验证不是可选项**：这两条都是「写完跑一遍绿，再故意改坏一次」才暴露的。

**7. 未定义的 CSS 变量什么都不画，而且没有任何检查会说话**。
`var(--color-cell-pressed)`（不存在）不是错误，只是那条声明整个消失。
铁律 1 的守卫只管「有没有写死颜色」，管不了反过来那半边。J13 补了守卫，
落地当场抓出三个真的：通话页静音按钮的背景与字色两个 token 从来不存在，
外加我自己二十分钟前写的 `--fs-body`。

### J4 为什么砍掉「Kotlin 现场生成」

原计划要让 Kotlin 在进程被杀后自己调 chat 端点产消息，前提写的是「key 从 Keystore
读，本来就存在原生侧」。**这句是错的**：API key 由 `src/lib/keystore.ts` 用
**`extractable: false`** 的 WebCrypto 主密钥封在 IndexedDB 里，Kotlin 取不出来——
不是难，是密码学上不可能。要让它可能只能把主密钥改成可导出，等于为一个功能
拆掉铁律 2 对所有 key 的保护。

按计划自己写的中止线执行，换来的架构反而更好：**JS 决定说什么、何时说；Kotlin
只负责送到。** 后台路径因此不含任何 LLM 调用，铁律 6 在这条路上成了结构性不可
违反（没有调用点可以判错 tier），也没有第二个内容生产者去破铁律 5。
