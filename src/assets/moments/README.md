# 朋友圈配图素材槽位

把 `.png` / `.jpg` / `.jpeg` / `.webp` 图片直接丢进这个目录即可 —— **不需要改任何代码**。

Vite 在构建时用 `import.meta.glob` 扫描本目录（见 `src/data/moments-images.ts`），
只要这里出现至少一张图，朋友圈就会自动改用真实配图，不再发占位渐变；
目录为空时则回落到程序生成的占位图，保证 feed 不会开天窗。

已发布的动态存的是不透明的 `img:<文件名>` 引用而非 URL，所以：

- 换图不会改动已存的帖子；
- 删掉某张图后，引用它的旧帖会回落到一张**稳定的**占位渐变（按文件名哈希选取），
  版式不会塌，也不会出现裂图。

命名随意，但建议用有意义的文件名（`sunset-beach.jpg` 好过 `IMG_2381.jpg`），
因为文件名就是引用键，改名等同于换图。
