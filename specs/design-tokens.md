# spec: 设计 Token 体系

**文件**：`src/styles/tokens.css`（唯一可写死颜色处）、`reset.css`、`app.css`。
**基准**：微信大陆 Android 8.0.x 浅色。以用户真机截图叠图校准，容差个位 dp。

## 分层
- `--wx-*` 原始调色板（微信标定值，组件禁止直接引用）。
- `--color-*` 语义别名（组件只引用这些）。深色模式 V3 = 在 `[data-theme="dark"]` 下重定义
  这一层，组件零改动。

## 关键标定值（易穿帮三处，重点盯）
- 页面底 `#EDEDED`；导航栏同色（非白、无底部分割线，标题居中 17px Medium）。
- 自己气泡 `#95EC69` 浅绿 **黑字**（`--color-bubble-self-text: --wx-ink`），不是白字。
- 头像 `--avatar-radius: 5px` **方圆角，不是圆形**。
- 品牌绿 `#07C160`、红点 `#FA5151`、链接蓝 `#576B95`、金额橙 `#FA9D3B`。

## 字体字号
- 不打包字体，用系统中文黑体（微信 Android 亦然）。
- 字号：导航/气泡/昵称 17、摘要/cell 副 14、评论 15、时间 12、小灰字 13、角标 11。
- 字重仅 Regular(400) + Medium(500)，**中文禁 Bold**；行高 ≈1.4；fontScale 锁 1.0。

## 验收
- [ ] `pnpm lint` 通过（无硬编码颜色）。
- [ ] 会话列表/聊天页与真机截图叠图，配色、头像方圆角、字号层级三处零差异。
- [ ] edge-to-edge：导航延伸入状态栏，safe-area inset 生效。

## 已知坑
- 导航标题用**绝对居中 + 侧按钮浮层**，不用 `1fr auto 1fr` grid（auto 轨道会被挤压导致
  百分比 max-width 解析异常，标题被误截断）。见 `app.css .navbar`。
